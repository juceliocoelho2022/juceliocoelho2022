# ⭐ Projetos em destaque

## 🚚 [LogiFlow — Event-Driven Logistics](https://github.com/juceliocoelho2022/logiflow-event-driven-logistics)

Sistema de logística orientado a eventos construído com **Java 21, Spring Boot, Apache Kafka, PostgreSQL, Docker e React**.

**Engenharia aplicada:**
- comunicação assíncrona entre serviços;
- Transactional Outbox;
- processamento idempotente por `eventId`;
- retry para falhas transitórias;
- Dead Letter Topic;
- Flyway;
- Swagger/OpenAPI;
- painel web e Docker Compose.

`Java 21` `Spring Boot` `Kafka` `PostgreSQL` `Docker` `React` `Outbox` `DLT`

`Java 21` `Spring Boot` `Kafka` `PostgreSQL` `Docker` `GitHub Actions`
